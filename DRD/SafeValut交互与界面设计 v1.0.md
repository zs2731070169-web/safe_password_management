## 1. 设计概述

### 1.1 设计目标

将 PRD 的产品定位「指纹一按，密码到手」转化为可感知的视觉语言：让用户在打开 App 的瞬间就感到**安全、被保护、值得信赖**，同时把核心操作压缩到 **≤ 3 步、≤ 3 秒**，做到「零学习成本」。

| 设计目标 | 落地手段 |
| --- | --- |
| 安全感可视化 | 锁形图标、盾牌徽标、密文 ●●● 默认态、解锁动效；敏感页防截屏模糊 |
| 取用最快 | 列表项直出「复制密码」按钮；详情页大号复制按钮；解锁后一步到位 |
| 零学习成本 | 单一主任务突出、底部 Tab 直达、文案口语化、关键操作有引导 |
| 照顾数字弱势用户 | 大字体模式、48dp 以上点击热区、高对比度、一键复制、二次确认防误触 |
| 信任透明 | 设置页展示「本地加密 / 不上云 / 核心开源」状态徽章 |

### 1.2 设计原则

| 原则 | 说明 |
| --- | --- |
| 信息脱敏优先（Privacy by Default） | 密码字段任何场景默认以 `●●●●●●` 呈现；明文需主动触发且有时限。 |
| 安全感可视化 | 用锁/盾/指纹等隐喻和绿色「已加密」状态，让用户随时感知数据是安全的。 |
| 最少操作（Fewest Taps） | 高频路径（解锁→取密码）零冗余；按钮直达，不藏二级菜单。 |
| 防误触（Fail-Safe） | 删除、覆盖、重置等破坏性操作一律二次确认，且危险按钮远离常用区。 |
| 一致性 | 同类元素（复制、显示/隐藏、强度条）全局统一样式与位置。 |
| 反馈即时 | 每次复制、保存、解锁失败都有明确 Toast / 状态变化，≤ 200ms 响应。 |
| 包容性 | 字号可放大不破版；颜色不作为唯一信息载体（配图标/文字）。 |

### 1.3 设计语言 / 风格关键词

> **可信赖（Trustworthy）· 安全（Secure）· 轻量（Light）· 清晰（Clear）· 友好（Friendly）**

- 整体走 **现代极简 + 卡片化** 风格，留白充足，弱化装饰，强化内容与操作。
- 主视觉隐喻：**盾牌 + 锁 + 指纹**，传达「保护」语义。
- 圆润几何（中等圆角），降低工具类产品的冷硬感，提升亲和力。
- 数字与密码使用**等宽字体**，提升可读性、避免 `0/O`、`1/l/I` 误读。

## 2. 设计规范（Design Tokens）

> 以下数值为基准值，研发可直接映射为变量。尺寸单位统一用 **dp/pt**（1pt ≈ 1dp，按平台像素密度换算）。

### 2.1 色彩系统

#### 2.1.1 品牌主色与辅助色（浅色模式）

| Token | 名称 | HEX | 使用场景 |
| --- | --- | --- | --- |
| `color/primary` | 主色 · 信任蓝 | `#2563EB` | 主按钮、关键图标、选中态、链接、强调 |
| `color/primary-pressed` | 主色按压态 | `#1D4ED8` | 主按钮按下/hover |
| `color/primary-light` | 主色浅底 | `#DBEAFE` | 选中背景、信息提示底色、徽章底 |
| `color/secondary` | 辅助色 · 沉稳青 | `#0EA5A4` | 次要强调、健康度优秀辅助点缀 |
| `color/accent` | 点缀色 · 盾牌金 | `#F59E0B` | 安全引导高亮、恢复码强调（克制使用） |

> 选用「信任蓝」作主色：蓝色在金融/安全领域最具信赖联想，饱和度适中不刺眼，对老年用户友好。

### 2.2 字体规范

#### 2.2.1 字体家族

| 用途 | iOS | Android | 说明 |
| --- | --- | --- | --- |
| 文本/标题 | SF Pro / PingFang SC | Roboto / Noto Sans SC | 系统默认中文字体，保证清晰度 |
| 数字/密码（等宽） | SF Mono | Roboto Mono / JetBrains Mono | 密码、恢复码、强度数值等宽展示，避免字符误读 |

#### 2.2.2 字号阶梯（Type Scale · 标准模式）

| 级别 | 字号(pt) | 字重 | 行高(pt) | 使用场景 |
| --- | --- | --- | --- | --- |
| Display | 32 | Bold 700 | 40 | 健康分大数字、引导页主标题 |
| H1 | 24 | Bold 700 | 32 | 页面主标题 |
| H2 | 20 | Semibold 600 | 28 | 卡片标题、分区标题、弹窗标题 |
| Title | 17 | Semibold 600 | 24 | 列表项主名称、按钮文字 |
| Body | 16 | Regular 400 | 24 | 正文、输入框文字、说明 |
| Body-Strong | 16 | Medium 500 | 24 | 强调正文 |
| Caption | 14 | Regular 400 | 20 | 账号、辅助说明、时间戳 |
| Footnote | 12 | Regular 400 | 16 | 标签、最次要信息 |
| Mono-Password | 18 | Medium 500（等宽） | 26 | 密码/恢复码明文展示 |

#### 2.2.3 大字体（无障碍）模式

- 跟随系统「动态字体（Dynamic Type / 字体大小）」，所有文本支持缩放，**最高放大至 200%**（PRD 7.3 大字体要求）。
- 大字体模式下：列表项高度自适应（不裁切），双行文本允许换行不截断，按钮高度随之增大但不小于 56dp。
- 提供 App 内独立的「大字体模式」开关（设置页），开启后基准字号整体 +2pt，行高同步放大，图标按 1.2× 放大。
- 等宽密码字体在大字体模式下最大放大至 24pt，保证老年用户可读。

| 层级 | 阴影参数 | 应用 |
| --- | --- | --- |

### 2.4 图标风格

| 项目 | 规范 |
| --- | --- |
| 风格 | **线性图标（Outline）为主**，描边 2dp，圆角端点；选中态/状态徽章用**填充（Filled）**。 |
| 网格 | 24×24dp 基础网格，关键视图边距 2dp。 |
| 标准尺寸 | 列表项图标 24dp；Tab 图标 24dp；按钮内图标 20dp；大图标（空状态/引导）64–96dp。 |
| 平台图标 | 条目图标按平台名/URL 自动匹配品牌图标，缺省用「首字母圆形色块」（背景取名称哈希色，文字白）。 |
| 安全语义图标 | 锁（lock）、盾（shield）、指纹（fingerprint）、面容（face-id）、眼睛（显示/隐藏）、复制（copy）统一字形。 |

## 3. 通用组件库

> 每个组件给出：用途、规格、状态。研发据此组件化复用。

### 3.1 按钮（Button）

| 类型 | 用途 | 背景 | 文字 | 高度 | 圆角 |
| --- | --- | --- | --- | --- | --- |
| Primary 主按钮 | 页面主操作（解锁、保存、复制密码） | `#2563EB` | 白 17pt Semibold | 52dp | 12dp |
| Secondary 次按钮 | 次要操作（换一个、取消） | 透明 + 1.5dp 主色描边 | 主色 17pt | 52dp | 12dp |
| Tertiary 文字按钮 | 弱操作（忘记主密码、跳过） | 透明 | 主色 16pt | 44dp | — |
| Danger 危险按钮 | 删除、清空、重置 | `#DC2626` | 白 17pt | 52dp | 12dp |
| Danger-Ghost | 危险次操作 | 透明 + 红描边 | 红 17pt | 52dp | 12dp |
| FAB 悬浮按钮 | 新增条目「+」 | 主色圆形 | 白 + 号 28dp | 56dp 圆 | full |

**状态**：默认 / 按压（背景加深 8%）/ 禁用（不透明度 40%，不可点）/ 加载（文字替换为旋转 Spinner，按钮锁定）。
**热区**：实际可点区域 ≥ 48×48dp（小于视觉尺寸时外扩透明热区）。

```
┌──────────────────────────────┐   ┌──────────────┐  ┌──────────────┐
│         立即解锁  (Primary)   │   │  取 消(Sec)  │  │ 删 除(Danger) │
└──────────────────────────────┘   └──────────────┘  └──────────────┘
        忘记主密码？(Tertiary)
```

### 3.2 输入框（Text Field）

```
└──────────────────────────────────────┘
```

| 属性 | 规范 |
| --- | --- |
| 高度 | 52dp（大字体 ≥ 60dp） |
| 内边距 | 左右 16dp |
| 描边 | 默认 `#E5E7EB` 1dp；聚焦 `#2563EB` 2dp；错误 `#DC2626` 2dp |

| 错误态 | 描边变红 + 下方红色 12pt 文案（如「名称不能为空」） |
| 清除 | 聚焦且有内容时右侧出现「×」清除按钮 |

| 属性 | 规范 |
| --- | --- |
| 位置 | 底部 Tab 上方居中，距底 96dp |

### 3.5 对话框 / 二次确认（Dialog）

```
        ┌───────────────────────────────────┐
        │           删除这条密码？             │ ← 标题 20pt
        │                                    │
        │  删除后将进入回收站，保留 7 天，      │ ← 说明 16pt
        │  到期彻底删除且无法恢复。            │
        │                                    │
        │   ┌─────────┐     ┌─────────────┐  │
        │   │  取 消   │     │   删 除      │  │ ← 危险操作右侧/红色
        │   └─────────┘     └─────────────┘  │
```

## 6. 状态与反馈设计

### 6.1 加载状态

| 场景 | 表现 | 时长预期 |

| 健康全部健康 | 太棒了，全部密码都很安全！ | 庆祝插画（绿） |

### 6.3 错误状态

| 错误 | 表现 |
| --- | --- |
| 输入校验失败 | 输入框红框 + 下方红色 12pt 文案 |
| 主密码错误 | 输入框抖动 + 红色「主密码不正确，还可尝试 N 次」 |

| 备份密码错误 | 「备份密码不正确，请重试」 |
| 生物识别不可用 | 自动降级主密码，提示「请使用主密码解锁」 |

### 6.4 复制成功反馈

- 通用复制：Toast「已复制」（绿 ✓，2s）。
- 复制密码：Toast「已复制密码，60 秒后自动清除剪贴板」（3s）+ 后台启动 60s 清除（仅剪贴板内容仍为该密码时执行，CP-03）。

### 6.5 锁定 / 失败次数超限

```
┌────────────────────────────────────────┐
│                  🔒                       │
│         尝试次数过多，已临时锁定           │
│             请 00:27 后重试               │ ← 倒计时
│         （连续失败将延长锁定时间）         │
│              改用恢复码找回 ›              │ ← 提供出口
└────────────────────────────────────────┘
```
连续 5 次失败锁定 30 秒，次数递增延长（SEC-07）；锁定期间禁用解锁入口，提供「忘记主密码 / 恢复码找回」出口；倒计时实时刷新。

### 6.6 自动锁定

退后台/熄屏立即加锁（SEC-08）；前台无操作超时（默认 60s，可设）自动回到解锁页（SEC-09）；锁定瞬间所有明文回密文，多任务快照遮罩。

| 密文/明文 | `●` 与等宽明文均用主文字色；倒计时数字次色 |
| 图片/插画 | 提供深色版本插画；品牌盾牌在深色下描边提亮 |
| 注意 | 不用纯黑背景；切换有 0.2s 渐变过渡 |

## 8. 无障碍与机型适配

### 8.1 大字体与可读性

- 全文支持系统动态字体，最高 200% 缩放不破版；提供 App 内「大字体模式」（基准 +2pt）。
- 列表项、按钮高度随字号自适应，文本允许换行不截断。
- 密码等宽字体优先，避免 `0/O`、`1/l/I` 误读（生成器默认提供「排除易混淆」选项）。

### 8.2 对比度（WCAG AA）

| 文本类型 | 对比度要求 |
| --- | --- |
| 正文（< 18pt） | ≥ 4.5:1 |
| 大文本（≥ 18pt 或 14pt Bold） | ≥ 3:1 |
| 图形/控件边界 | ≥ 3:1 |

- 颜色**不作为唯一信息载体**：健康强/中/弱、密码强度均同时用「颜色 + 图标 + 文字」三重编码。

### 8.3 点击热区

- 所有可点元素热区 ≥ 48×48dp；相邻可点元素间距 ≥ 8dp，防误触。
- 危险操作（删除/清空）与常用操作保持视觉与位置距离。

### 8.4 多机型与刘海 / 灵动岛

- 关键内容遵守安全区域（Safe Area）；顶部标题/搜索框下移避让刘海/灵动岛；底部 Tab 避让 Home Indicator。
- 适配 iOS 14+ / Android 9+ 主流尺寸（PRD 7.3）；小屏 SE 与大屏 Max/Pad 弹性栅格自适应。
- 横屏：工具属性以竖屏为主，横屏保持可用（表单单列居中限宽）。

### 8.5 读屏与语义

- 为图标按钮提供无障碍标签（如「复制密码」「显示密码」「删除条目」）。
- 密文字段读屏播报「密码已隐藏」，不读出明文；明文显示时才可读。

> 采用**底部 Tab** 而非抽屉：4 个核心入口、扁平、零学习成本、单手可达，符合「最少操作」与老年友好。
