# SafeVault uni-app 视图迁移规则手册（子代理必读）

把源工程 `safevault_ui/src/views/<feature>/` 的 Vue3+vue-router 视图迁移到
`safevault_app/pages/<feature>/index.vue`（或对应文件）。**只写 `safevault_app/`，禁止改 `safevault_ui/`。**
全程简体中文注释，保持源工程高密度中文注释风格。`@` 别名在 app 工程指**项目根**（不是 src）。

## 一、标签替换（template 段）
- `<div>`→`<view>`，`<header>/<footer>/<section>/<nav>/<main>/<ul>/<li>/<label>/<p>`→`<view>`
- `<span>/<strong>/<em>/<small>/<h1>~<h6>`→`<text>`
- `<img>`→`<image>`（src 不变；本地图用 `@/static/...` 或相对路径）
- `<button>` 保留（uni 有内置 button；`type="button"` 可留）
- `<svg>/<path>` 不要直接写：uni app-vue 编译器会丢失 :d/:viewBox 等绑定，App 端不渲染。图标统一走
  `@/components/icons/AppIcon.vue`（已改用 CSS mask + background-color 渲染，App+H5 一致）；新增图标只需
  往 `components/icons/icon-paths.js` 加一条 `{ viewBox, paths }`（path 须为闭合实心字形，mask 取 alpha）
- **关键：uni 中 `<view>` 的直接子文本在 App 端不渲染！** 混排文本（如 `<view>前缀<strong>强调</strong>后缀</view>`）必须整体放进 `<text>`：`<text>前缀<text class="xx">强调</text>后缀</text>`（text 可嵌 text）。纯文本块用 `<text>` 包裹。
- `@click.self` 在 App-vue/H5 支持，可保留。事件 `.passive` 修饰符去掉（uni 不识别，改裸 `@touchstart`）。

## 二、表单 input（uni input 与 HTML 差异大）
- 密文：`:type="x?'text':'password'"` → 用 `:password="!x"` 属性（去掉 type）
- 取值：`@input="fn"` 里 `e.target.value` → `e.detail.value ?? e.target.value`
- 回车：`@keydown.enter="fn"` → `@confirm="fn"`；`enterkeyhint="search"` → `confirm-type="search"`
- 移除 Web 专属属性：`autocomplete` `autocapitalize` `autocorrect` `spellcheck` `type="search"`
- 自动聚焦：DOM `.focus()` → uni input 的 `:focus="bool"` 属性
- checkbox/radio/switch：源工程多为自绘（隐藏原生 input + CSS）。uni 无 `<input type=checkbox>`，
  改为：去掉隐藏 input，容器加 `@click` 切换状态，勾选态用 `:class` + 对勾用 `v-if`（参考 components/RecoveryCodeReveal.vue 的 rc-ack 改法）。原生 range slider 同理自绘。
- 注意 `<input>` 的 CSS 选择器若依赖 `:checked + .box`，改造后失效，改用 `.box--checked` 类。

## 三、导航（vue-router → uni）
- 删除 `import { useRouter, useRoute } from 'vue-router'` 与 `const router=useRouter()/route=useRoute()`
- 改 `import { navTo, navReplace, navBack } from '@/utils/navigation'`
- `router.push({ name:'X' })` → `navTo('X')`
- `router.push({ name:'X', params:{ id } })` → `navTo('X', { id })`
- `router.replace({ name:'X' })` → `navReplace('X')`
- `router.back()` → `navBack()`
- 取参：源 `route.params.id` / `route.query.x` → 在 `<script setup>` 顶层用 `onLoad`：
  ```js
  import { onLoad } from '@dcloudio/uni-app'
  const id = ref('')
  onLoad((query) => { id.value = query.id || '' })
  ```
  （`onLoad` 从 `@dcloudio/uni-app` 引入；query 同时承载源 params 与 query，因都降级为 query）
- 可用的 name：Unlock/MasterPassword/Onboarding/ResetPassword/Vault/Health/Generate/Settings/
  PasswordDetail/AddPassword/EditPassword/ChangeMasterPassword/RegenerateRecovery/RecoverData/Trash/CategoryManage/PrivacyPolicy

## 四、Element Plus → uni
- `import { ElMessage } from 'element-plus'` → `import { toastSuccess, toastError, toastInfo, showConfirm } from '@/utils/feedback'`
- `ElMessage.success(x)`→`toastSuccess(x)`；`.error`→`toastError`；`.info`/`.warning`→`toastInfo`；裸`ElMessage(x)`→`toastInfo(x)`
- `ElMessageBox.confirm(msg,title,opts)`（await + try/catch，取消时 reject）→
  `const ok = await showConfirm({ title, content: msg, confirmText, cancelText, danger })`；`ok` 为布尔，**取消返回 false（不抛）**，把原 try{确认}catch{取消} 改为 `if(ok){...}else{...}`
- `ElInput` → uni `<input>`（见第二节）

## 五、localStorage / 平台 API
- `localStorage.*` 在 App 端已由 main.js 的全局垫片覆盖（getItem/setItem/removeItem/clear），**逻辑代码无需改**。
- `document.*` / `window.*`（DOM 事件、visualViewport、createElement 等）App 端不存在：
  - 能去则去；必须保留的浏览器行为用条件编译 `// #ifdef H5 ... // #endif` 包裹；
  - canvas 绘制：H5 用 `document.createElement('canvas')`，App 用 `<canvas canvas-id>` + `uni.createCanvasContext`（参考 RecoveryCodeReveal.vue）。
- `navigator.clipboard` 等：改走 `@/services/clipboard` 的 `copyText`（已 uni 化）。

## 六、SHEET 页（详情/新增/编辑/改密/恢复码/回收站/分类/隐私）
这些页是自右滑入的子页（pages.json 已配 pop-in）。若源页用了「左滑收回」手势，接入：
```js
import { useSheetDismiss } from '@/composables/useSheetDismiss'
const { sheetStyle, onTouchStart, onTouchMove, onTouchEnd } = useSheetDismiss()
```
模板根：`<view :style="sheetStyle" @touchstart="onTouchStart" @touchmove="onTouchMove" @touchend="onTouchEnd">`
顶栏返回按钮：`@click="navBack()"`。

## 七、Tab 页（vault/health/generate/settings）
用共享外壳 `@/components/TabShell.vue` 包裹内容（替代源 MainTabLayout）：
```vue
<TabShell active="vault" v-model:keyword="keyword" :searchable="true" :placeholder="..." :search-label="..." :show-fab="true" @add="goAdd">
  <!-- 该 Tab 的滚动内容（去掉源 View 里自带的顶栏/底栏，只留主体） -->
</TabShell>
```
- vault: active="vault" searchable show-fab，keyword 绑 vaultStore.keyword，@add→navTo('AddPassword')
- health: active="health" searchable，keyword 绑 healthStore.keyword
- generate: active="generate" searchable=false
- settings: active="settings" searchable=false
源 MainTabLayout 的 keyword computed 逻辑下放到各 Tab 页（各自绑自己 store）。

## 八、组件引用路径
公共组件已迁好，直接引用：
- `@/components/icons/AppIcon.vue`、`@/components/AppHeader.vue`、`@/components/AppTabBar.vue`
- `@/components/PasswordField.vue`、`@/components/PasswordStrength.vue`、`@/components/BiometricPrompt.vue`
- `@/components/ConfirmSheet.vue`、`@/components/IdentityVerifyModal.vue`、`@/components/RecoveryCodeReveal.vue`
- `@/components/AddFab.vue`、`@/components/TabShell.vue`
私有子组件（源 views/<feature>/components/*）：复制到 `pages/<feature>/components/` 并按本手册 uni 化，page 内用相对路径 `./components/Xxx.vue` 引用。
composables 已迁好：`@/composables/useXxx.js` 直接用。stores/utils/services 已迁好。

## 九、样式
- SCSS Token 已全局注入（变量/mixin 直接用），禁止硬编码颜色/尺寸。
- 选择器若依赖被替换标签名（如 `p {}`、`span {}`、`strong {}`），改为对应 `text {}` 或类选择器。
- 100vh/100dvh：uni 用 100vh 即可（dvh 部分端不支持，去掉 dvh 那行或只留 vh）。
- `:focus-visible`/`:hover` 在 App 端无效但不报错，保留无害。

## 十、自检
迁移后该页应：无 vue-router/element-plus/Capacitor import 残留；无裸 document/window（除 #ifdef H5 内）；
input 用 uni 语法；混排文本包在 text 内；导航用 navTo/navBack。
